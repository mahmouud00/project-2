# نقل البرنامج من سيرفر المصنع للسيرفر الأونلاين (VPS) بنفس الداتا

الداتا كلها (العملاء، العروض، الأوامر، المخازن، الخزينة، المكتبة، المستخدمين والصلاحيات) **وصور النماذج واللوجو**
بتتنقل في ملف واحد. مفيش مزامنة بين السيرفرين: بعد النقل السيرفر الجديد هو اللي شغالين عليه، والقديم يتقفل.

## ١. على سيرفر المصنع (آخر يوم شغل على السيرفر القديم)
PowerShell كمسؤول:
```powershell
Stop-Service MYTechServer          # محدش يسجل حاجة جديدة أثناء النقل
cd C:\MYTech\config
$v = (Get-Content C:\MYTech\current.json | ConvertFrom-Json).path
& "C:\MYTech\$v\mytech-server.exe" export --out C:\MYTech\mytech-move.zip
```
انقل `C:\MYTech\mytech-move.zip` للسيرفر الجديد (فلاشة / Google Drive). **الملف فيه بيانات العملاء: متبعتهوش لحد.**

## ٢. على السيرفر الجديد (بعد ما يتسطّب بالخطوات اللي MYTech بتبعتها)
```bash
sudo docker compose stop api
sudo docker compose run --rm -v /root/mytech-move.zip:/move.zip api python -m app.cli import /move.zip
sudo docker compose start api
```
الأمر بيرجّع الداتا والصور، وبيعمل نسخة احتياطية من أي داتا كانت على السيرفر الجديد قبلها.

## ٣. الترخيص
الترخيص مربوط بالجهاز. بعد النقل: البرنامج هيطلب ترخيص ← خد «بصمة الجهاز» من شاشة الدخول ← اعمل ترخيص جديد من
**MYTech-License-Tool** ← ركّبه من نفس الشاشة.

## ٤. الأجهزة والموبايلات
في كل جهاز وموبايل: شاشة الدخول ← «تغيير السيرفر» ← `https://app.<الدومين>` ← الدخول بنفس المستخدم وكلمة المرور.

## ٥. التأكد
- افتح عميل قديم وأمر تصنيع قديم وكشف التقطيع بتاعه.
- افتح نموذج من المكتبة واتأكد إن صورته ظاهرة.
- اعمل «نسخة دلوقتي» من «الترخيص والنسخ».
بعدها بس اقفل السيرفر القديم (وسيب عليه الداتا كام أسبوع احتياط).
