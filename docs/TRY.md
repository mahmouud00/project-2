# تجربة البرنامج على جهازك

لسه مفيش واجهة، فالتجربة بتبقى من **صفحة الـ API** في المتصفح (`/api/docs`): كل عملية ليها زرار **Try it out** بتملا فيه البيانات وتضغط **Execute**.

## 1) التسطيب (مرة واحدة)
1. نزّل **Docker Desktop** من docker.com وسطّبه وشغّله، واستنى لحد ما يقول إنه Running. لو طلب منك تفعيل WSL 2 وافق، وممكن يطلب restart.
2. نزّل الكود من GitHub كملف ZIP: افتح الريبو ← غيّر الفرع لـ `claude/youthful-maxwell-n6mca9` ← **Code ← Download ZIP**، وفكّه في فولدر (مثلًا `C:\mytech`).
3. افتح **PowerShell** في الفولدر ده (كليك يمين على الفولدر ← Open in Terminal) واكتب:
   ```
   docker compose up --build
   ```
   أول مرة بياخد كام دقيقة. لما تلاقي السطر `Uvicorn running on http://0.0.0.0:8000` يبقى البرنامج جاهز.
4. افتح المتصفح على: **http://localhost:8000/api/docs**

للإيقاف اضغط `Ctrl+C`. والمرة الجاية `docker compose up` بس، والبيانات بتفضل محفوظة.
عشان تمسح كل حاجة وتبدأ من الأول: `docker compose down -v`.

## 2) بيانات الدخول الجاهزة
| الحساب | username | password | client_id (كود الشركة) |
|---|---|---|---|
| مدير المصنع التجريبي | `admin` | `Admin@12345` | `DEMO` |
| حسابك كـ MYTech (المكتبة) | `vendor` | `Vendor@12345` | `__platform__` |

في صفحة `/api/docs` اضغط زرار **Authorize** فوق على اليمين، واكتب الـ username والـ password، وفي خانة **client_id** اكتب كود الشركة، وبعدين اضغط Authorize. من هنا كل العمليات بتتنفذ بالحساب ده. وعشان تغيّر الحساب: Logout وبعدين Authorize تاني.

## 3) البيانات التجريبية الموجودة
- **سيستم مثال** اسمه `DEMO-SL` "مثال تجريبي: جرار (أرقام غير حقيقية)": ثوابت وخامات بلونين (أبيض وبيج) ونموذج "شباك جرار" بصورة واختبار مرجعي، ومنشور.
  ⚠️ **أرقام التخصيم فيه مجرد مثال، مش تخصيمات حقيقية.** دخّل سيستماتك الحقيقية بحساب `vendor`.
- **في المصنع التجريبي:**
  - إعدادات: ضريبة 14%، عربون 30%، سلاح منشار 4 مم.
  - 3 قوائم أسعار (عميل نهائي 30%، تاجر 15%، مقاول 20%).
  - مخزن فيه رصيد افتتاحي، وخزينة، ومورد.
  - عميل تجريبي ومعاه معاينة (فتحتين) وعرض سعر جاهز.

## 4) جرّب بالترتيب ده (بحساب admin)
| | العملية | الـ endpoint |
|---|---|---|
| 1 | شوف عرض السعر الجاهز: الأسعار، والضريبة، وتكلفة كل شباك، وتفاصيل الحساب | `GET /quotations` ثم `GET /quotations/{id}` |
| 2 | احسب شباك بمقاس من عندك | `POST /engine/calculate` (هات `model_id` من `GET /library/models?system_id=...`، و`system_id` من `GET /library/systems`) |
| 3 | وافق على العرض | `POST /quotations/{id}/status` ← `{"version": ..., "status": "accepted"}` |
| 4 | اعمل أمر تصنيع منه | `POST /work-orders/from-quotation` ← `{"quotation_id": "..."}` |
| 5 | شوف كشف التقطيع وخطة الأعواد والهالك والزجاج والإكسسوار والتكلفة | `GET /work-orders/{id}/manufacturing` |
| 6 | جرّب توافق قبل دفع العربون (هيرفض) | `POST /work-orders/{id}/stage` ← `{"version": ..., "to": "approved"}` |
| 7 | ادفع العربون في الخزينة | `POST /cash-transactions` ← `direction: in`، `party_type: customer`، `party_id`، `work_order_id`، `amount`، `cashbox_id` (من `GET /cashboxes`) |
| 8 | ابدأ التصنيع | `POST /work-orders/{id}/stage` ← `approved` ← `manufacturing` |
| 9 | اطلب البضاعة للأمر (الحسابات تأكد وبعدين تتطلب) | `GET /work-orders/{id}/material-needs` ← `POST /purchase-orders` ← `/approve` ← `/status` |
| 10 | كمّل المراحل: تجميع، جودة، تسليم | `POST /work-orders/{id}/stage` |

**ملاحظة:** أي تعديل (`PATCH` أو تغيير مرحلة) محتاج `version` بتاع السجل، وده بتلاقيه في آخر رد جالك. لو بعته قديم هيرجعلك `409`، وده مقصود: علشان تعديل حد مايمسحش تعديل حد تاني.

## 5) جرّب تضيف سيستم بنفسك (بحساب vendor)
اتبع `docs/LIBRARY.md`: سيستم ← ثوابت ← خامات ← نموذج ← اختبار مرجعي ← `publish`.
بعد النشر، ادخل بحساب `admin` وهتلاقي السيستم الجديد ظاهر عند المصنع، وتقدر تحسب بيه وتعمل عروض أسعار.

## ملاحظات
- النسخة التجريبية دي شغالة بوضع **online** (الاشتراك متسجل في قاعدة البيانات)، عشان ماتحتاجش ملف ترخيص. نسخة الأوفلاين الحقيقية عند العميل بتتسطب بالطريقة اللي في `docs/INSTALL.md`.
- الباسوردات اللي في `docker-compose.yml` للتجربة على جهازك بس.
