# تصور الواجهة (Mockups)

صور مقترحة لواجهة برنامج الديسكتوب (عربي، من اليمين للشمال، مقاس 1440×900).
دي **تصور للمناقشة**، مش الواجهة النهائية؛ كل الأرقام والأسماء فيها أمثلة.

| الشاشة | الصورة | المصدر |
|---|---|---|
| الدخول واكتشاف السيرفر | `png/login.png` | `login.html` |
| لوحة التحكم | `png/dashboard.png` | `dashboard.html` |
| عرض السعر | `png/quote.png` | `quote.html` |
| أمر التصنيع وخطة التقطيع | `png/workorder.png` | `workorder.html` |
| محرر المكتبة (MYTech) | `png/library.png` | `library.html` |

- المقاسات كلها بالسم، والعرض قبل الارتفاع. وتخصيم كل عنصر (حلق، ضلفة، باكتة...) معروض عرض + ارتفاع.
- اللوجو والألوان من `design/brand/` (`logo-transparent.png` و`mark-transparent.png` بخلفية شفافة للأسطح الغامقة).
- نظام التصميم المشترك: `style.css` (الألوان، الخط Cairo محليًا في `fonts/`، المكونات) و`shell.js` (القائمة الجانبية والشريط العلوي) و`draw.js` (رسم الشبابيك).
- إعادة توليد الصور: افتح أي ملف HTML في المتصفح، أو صوّره بـ Playwright على 1440×900.
